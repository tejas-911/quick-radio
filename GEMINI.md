# Project Guidelines & Preferences

## Version Control (Git) Discipline
- **Initialize Git Repositories**: When starting out on any software project or codebase that does not already have version control, initialize a Git repository (git init) with a proper .gitignore.
- **Stage Files & Propose Commit Messages (Do Not Commit)**: At the end of every major change, feature addition, optimization, or bug fix, stage the changed files (`git add`) and provide a clear, professional commit message following conventional commit formatting (e.g., `feat:`, `fix:`, `perf:`, `refactor:`) with bullet points summarizing the key modifications. NEVER run `git commit` directly; the user will manually perform the commit.
